# Wi-Fi Connectivity

Use this guide when your laptop cannot join the office wireless network, keeps disconnecting, or the connection is very slow.

## Cannot connect to the office Wi-Fi
1. Make sure Wi-Fi is turned on and Airplane mode is off.
2. Select the corporate network named CORP-SECURE (not the guest network). Sign in with your network username and password.
3. If you recently changed your password, forget the network, then reconnect and enter the new password.
4. Restart the laptop's wireless adapter: open Network settings, disable the adapter, wait ten seconds and enable it again.

## Connection drops or is slow
1. Move closer to an access point and away from microwaves or thick walls.
2. Switch from the 2.4 GHz band to the 5 GHz band if both are visible.
3. Run a speed test. Speeds below 5 Mbps in the office should be reported with your location and the time.
4. Reboot the laptop to clear stale network settings.

## When to raise a ticket
If several colleagues in the same area are affected, raise an incident with category Network / Wi-Fi and mention the floor and area. Network Support will investigate access point issues.
