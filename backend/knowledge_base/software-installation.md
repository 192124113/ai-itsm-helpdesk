# Software Installation and Provisioning

Employees do not have local administrator rights. Approved software is installed remotely by the provisioning system.

## How to get software
1. Ask the helpdesk chatbot or the self-service portal, for example "I need Visual Studio Code".
2. The request is checked against the software catalogue. Catalogue items are pre-approved and need no manager approval.
3. A ServiceNow service request is created and the provisioning system installs the software on your laptop, usually within a few minutes while the laptop is online.
4. You receive a status update when the install is complete. Restart the application if it was open.

## Approved catalogue
Visual Studio Code, Google Chrome, Slack, Zoom, Microsoft Teams, Python 3.12, Git, Postman, Docker Desktop and 7-Zip.

## Software not in the catalogue
Software that is not in the catalogue needs a security review and manager approval. Raise a service request and describe the business need and licence cost.

## Troubleshooting a failed installation
Make sure the laptop is online and connected to the VPN or the office network, has at least 5 GB of free disk space and has been restarted recently. If provisioning still fails raise an incident with category Software / Installation.
