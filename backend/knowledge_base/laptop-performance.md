# Laptop Performance

Use this guide when your laptop is slow, freezes, or the fan runs loudly all the time.

## Quick fixes
1. Save your work and restart the laptop. A restart at least once a week keeps updates applied and memory clean.
2. Open Task Manager and sort by CPU and Memory. Close applications using a large share that you do not need.
3. Check free disk space. Keep at least 15 percent of the drive free; run Disk Cleanup and empty the recycle bin.
4. Close browser tabs you are not using. Each tab consumes memory.
5. Install pending operating system updates and restart.

## Startup and background apps
Disable unneeded startup programs in Task Manager under the Startup tab. Avoid running video calls while large file syncs are active.

## Hardware signs
A battery that drains in under an hour, a very hot chassis or repeated blue screens may indicate hardware failure. Raise an incident with category Hardware / Laptop for Desktop Support.

## Automation
Clearing temporary files and application caches is approved for automated self-healing.
